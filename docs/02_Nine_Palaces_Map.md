## 3. 跨宫相生与对冲连锁效应
* **相生共振（木火通明）**：
  * 若玩家在【震三宫】建立研发中心，在【离九宫】开设品牌旗舰店，将激活“木生火”加成：新科技产品推向市场首月转化率额外 $+30\%$。
* **相克摩擦（水火不容）**：
  * 若企业将主品牌（离火属性）仓促向北方【坎一宫】扩张，而未先在【震三宫】设置过渡跳板，将遭受“水克火”反噬：当地客群不认同品牌定位，退货率高达 $45\%$。
